## 1. 프로젝트 배경

해외주식 투자자는 양도소득세 부담을 고려하면서도 장기 보유 계획이나 종목별 투자 판단을 유지하고 싶을 수 있습니다. 손실 중인 종목을 매도하면 같은 과세연도의 양도차익과 손익통산할 수 있지만, 세금만을 이유로 매도하는 것이 항상 적절한 선택은 아닙니다.

팀은 투자자가 **현재 보유를 유지하는 경우와 일부 종목을 매도하는 경우를 비교**하고, 예상 세금과 투자 조건을 함께 살펴볼 수 있는 서비스를 기획했습니다.

## 2. 주요 기능 — 팀 프로젝트 결과물

최종 발표자료에 소개된 서비스 흐름은 다음과 같습니다.

1. **내 계좌 분석**: 서비스에 등록된 해외주식 보유 현황과 예상 세금 확인
2. **AI 이벤트 분석**: 종목별 뉴스 제목·요약 내용을 분석해 주요 이슈 정리
3. **맞춤 조건 설정**: AI 챗봇을 통해 장기 보유 의사 등 고객의 투자 조건 정리
4. **절세 시나리오**: 실현손익, 평가손익, 설정 조건을 바탕으로 매도 시나리오별 결과 비교
5. **최종 리포트**: 선택한 시나리오의 예상 절세 효과와 매도 결과 확인

> 위 내용은 **팀 전체의 서비스 구성**입니다. 각 기능을 제가 직접 개발했다는 의미는 아닙니다.

## 3. 나의 기여

### 3-1. AI 챗봇의 응답 범위 검토 및 예외처리 요구

금융권 현직자에게서 챗봇은 정확한 답변뿐 아니라 **제공해서는 안 되는 답변을 제한하는 것**도 중요하다는 조언을 들었습니다. 이를 계기로 팀의 AI 챗봇이 서비스에서 제공하는 정보의 범위를 벗어나 특정 종목이나 매도 수량을 **직접 추천하지 않도록** 요청했습니다.

- **문제 인식**: 시뮬레이션 결과를 보여주는 것과 챗봇이 직접 매매를 권유하는 것은 구분할 필요가 있다고 판단
- **내가 한 일**: 종목 추천·매도 수량 직접 추천을 제한하는 요구사항 전달
- **확인**: 반영 후 챗봇에 직접 질문을 입력해 응답 제한 여부 테스트
- **남은 한계**: 테스트하지 않은 모든 질문에 대해서도 동일하게 작동하는지는 확인하지 못함

해커톤 종료 후 예외처리 방식을 살펴보니 프롬프트를 중심으로 구현되어 있었습니다. 이후 기준이 명확한 경우에는 조건문으로 먼저 처리하는 방법도 있다는 점을 추가로 학습했습니다. **조건문 방식은 제가 직접 구현한 내용이 아닙니다.**

### 3-2. 발표 대본 구성·검토 및 최종 발표

- AI를 활용해 발표 대본 초안 작성
- 팀원들이 발표에 담고자 한 의견을 반영해 내용 통합
- PPT 페이지별 내용과 대본이 어울리는지, 빠진 설명은 없는지 확인
- 실제로 읽어보면서 자연스럽게 발표할 수 있도록 문장 수정
- 해커톤 최종 발표 담당

### 3-3. Runway를 활용한 소개영상 제작

- Runway에 프롬프트를 입력해 최초 소개영상 생성
- 다른 컨퍼런스 영상을 참고해 광고처럼 시선을 끄는 표현과 구성을 시도
- YouTube 참고 링크를 제공해 수정을 요청했으나, 기대한 변화가 결과물에 충분히 나타나지 않음
- 최종적으로 우리금융그룹 광고를 연상시키는 로고 화면 추가

원하는 스타일을 AI 영상 생성 결과에 정확히 반영하는 데 한계가 있었던 경험입니다. 영상 제작의 세부 편집 방식이나 품질 개선 효과는 별도로 검증하지 않았습니다.

## 5. 구현 범위와 한계

이번 결과물은 **로컬 환경에서 확인한 시제품**으로, 실제 증권사 계좌와 연동한 서비스가 아닙니다. 실제 금융서비스 수준의 세금 계산 정확성을 확보한 상태도 아닙니다.

실서비스로 발전시키려면 취득원가·환율·거래비용을 포함한 세액 산출 검증, AI 응답 신뢰성, 개인정보 보호, 보안 및 준법 검토가 필요합니다. 마이데이터를 활용한 타 증권사 계좌 연계는 **향후 확장 아이디어**로 제시한 내용이며 이번 시제품의 구현 기능은 아닙니다.

## 6. 배운 점

이번 프로젝트에서 금융 서비스의 AI는 답변을 많이 제공하는 것만큼이나 **어떤 답변을 제공하지 않아야 하는지 범위를 정하는 일**이 중요하다는 점을 배웠습니다. 또한 몇 가지 질문을 직접 테스트했다고 해서 모든 예외상황이 검증된 것은 아니라는 한계를 인식했습니다.

발표 준비 과정에서는 팀원들의 의견과 AI 초안을 그대로 사용하는 대신, 실제 PPT의 내용과 대본을 대조하고 설명이 누락되지 않도록 검토했습니다. Runway 영상 제작 과정에서는 참고 자료를 제공하더라도 원하는 결과가 그대로 반영되지 않을 수 있음을 경험했습니다.
