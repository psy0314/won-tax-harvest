# Runway 소개영상 제작 프롬프트 (초기 기획)

> 본 문서는 영상 제작을 위해 작성한 **초기 프롬프트**입니다. 실제 영상에 모든 장면과 표현이 그대로 반영되었다는 뜻이 아닙니다. 로고 추가 전 60초 소개영상과 발표용 최종본은 별도 산출물입니다.

## 기획 요약
- 형식: 60초, 16:9, 한국어 타이포그래피 중심의 금융 서비스 광고
- 스타일: 파란색·흰색, 절제된 모션 그래픽, 높은 한글 가독성
- 흐름: 투자자 문제 제기 → 신고 인원 숫자 → 매도 고민 → 서비스 소개 → 세 가지 비교안 → 고객 가치 → 증권사 가치 → 긍정적 메시지 → 브랜드 마무리

## 장면별 원문 지시 요약
| 구간 | 장면 내용 |
| --- | --- |
| 0–5초 | 해외주식 수익 250만 원 초과에 대한 질문, 숫자 강조 |
| 5–9초 | 신고 인원 52만 3,709명 제시 및 카운트업 효과 요청 |
| 9–15초 | 매도 고민과 손실 종목 카드, TSLA·AAPL·MSFT·NVDA·GOOGL 카드 |
| 15–23초 | AI 분석 및 절세 매도 조합 추천이라는 초기 콘셉트 |
| 23–32초 | 최대 절세안·단일 종목안·뉴스 리스크 우선안 3개 카드 |
| 32–40초 | 계산 간소화와 개인화된 절세 전략 메시지 |
| 40–47초 | 고객과 증권사 양쪽의 기대효과 제시 |
| 47–54초 | 미래 수익에 대한 긍정적 메시지 |
| 54–60초 | ‘투자는 오늘, 절세는 미리’ 및 서비스 브랜드 마무리 |

## 추가 스타일 및 제약
- Smooth text motion, fade, slide, scale, card-based animations
- Clean sans-serif Korean fonts, balanced spacing, subtle financial UI graphics
- Avoid messy layouts, excessive colors, distorted Korean text, playful animation, and complex cinematic scenes

> 원문 전체에는 초안 단계의 수치·서비스 기능·수수료 관련 표현이 포함되어 있습니다. 위 표는 사용자가 제공한 프롬프트의 핵심 지시를 보존해 정리한 것이며, 수치의 정확성이나 최종 구현 여부를 검증한 자료는 아닙니다.
