PROBLEM & SOLUTION

절세 효과와 투자 전략을 함께 비교할 수 있을까?

해외주식 투자자는 같은 과세연도의 양도차익과 손실을 함께 고려할 수 있지만, 세금만을 이유로 매도하는 것이 항상 유리하지는 않습니다. 팀은 해외주식 보유자에게 계좌 현황 → 뉴스 이벤트 분석 → 투자 조건 설정 → 절세 시나리오 → 최종 리포트로 이어지는 5단계 비교 흐름을 제시했습니다.

위 기능은 팀 전체의 시제품 구성입니다. 제가 모든 기능을 개발했다는 의미는 아닙니다.

MY CONTRIBUTION

내가 맡은 작업과 확인 결과

01
AI 챗봇 응답 범위 검토

시작 조건 — 챗봇이 시뮬레이션 결과를 안내하는 것과 특정 종목·매도 수량을 직접 추천하는 것을 구분할 필요가 있었습니다.

수행 — 직접적인 종목·수량 추천을 제한하도록 팀에 요청하고, 반영 후 챗봇에 질문을 입력해 응답을 확인했습니다.

확인 결과와 한계 — 테스트한 일부 질문에서 제한 동작을 확인했습니다. 모든 질문 유형을 검증한 것은 아니며, 테스트 문항 원문·전체 응답 로그는 현재 공개 자료에 포함되어 있지 않습니다.

관련 챗봇 화면 보기 ↗화면은 기능 참고 자료이며 제한 테스트 자체의 증빙은 아닙니다.
02
발표 대본 구성·검토 및 최종 발표

시작 조건 — AI로 작성한 초안과 팀원 의견을 발표자료의 실제 페이지 흐름에 맞게 정리해야 했습니다.

수행 — 의견을 통합하고 PPT와 대본을 대조해 누락 여부를 확인했으며, 직접 읽어 보며 구어체로 수정한 후 최종 발표를 맡았습니다.

결과 — 최종 발표에 사용한 대본과 발표를 완성했습니다. 발표 효과를 수치로 측정하지는 않았습니다.

README의 개인 기여 기록 ↗발표 대본 원본 파일은 공개 가능 여부 확인 후 별도 연결 예정입니다.
03
Runway 소개영상 제작

시작 조건 — 발표에 사용할 서비스 소개영상을 제작하고자 했습니다.

수행 — Runway로 영상을 생성하고 참고 영상에 가까운 표현을 얻기 위해 수정을 요청했으며, 최종적으로 로고 화면을 추가했습니다.

결과와 한계 — 소개영상 산출물을 만들었으나 참고자료를 제공해도 원하는 변화가 충분히 반영되지는 않았습니다. 품질 개선 효과를 별도로 검증하지는 않았습니다.

영상 파일은 외부 공개 권한을 확인한 뒤 링크를 추가할 예정입니다.

LEARNING & LIMITATIONS

배운 점과 구현 범위

금융 AI 서비스에서는 답변을 잘하는 것뿐 아니라 제공하지 말아야 할 응답의 경계를 정의하는 일이 중요하다는 점을 배웠습니다. 해커톤 이후 응답 제한이 프롬프트 중심으로 처리된 것을 확인했고, 명확한 기준은 조건문으로 우선 처리할 수도 있음을 학습했습니다. 조건문 방식은 직접 구현하지 않았습니다.

이번 결과물은 로컬 시제품입니다. 실제 증권사 계좌 연동, 금융서비스 수준의 세액 정확성 검증, 모든 AI 응답에 대한 예외 테스트는 완료되지 않았습니다. 마이데이터 연계는 향후 확장 아이디어입니다.
